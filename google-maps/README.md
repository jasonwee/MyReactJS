# to begin
```
source init-env-nodejs26.sh
npx create-react-app google-maps --template typescript
cd google-maps
npm i @googlemaps/react-wrapper @googlemaps/markerclusterer
npm --save-dev i @types/google.maps @types/styled-components
```
